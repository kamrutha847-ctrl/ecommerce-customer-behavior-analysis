# Mini Project Management Web App

**Tech Stack:** Java, Spring Boot, MySQL, HTML, CSS

- Designed and developed a full-stack web application to manage projects, tasks, and team members using Spring Boot.
- Implemented task lifecycle tracking with **To-Do**, **In Progress**, and **Done** states, along with team member assignment workflows backed by MySQL.
- Applied RESTful architecture principles to support clean API design and practical project coordination use cases.
- Built a responsive HTML/CSS front end and followed a structured SDLC process with version control and deployment practices.
